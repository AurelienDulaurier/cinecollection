# CinéCollection

Gérer ses DVD et Blu-ray, ses souhaits, et les films et séries vus ou à voir. Windows 10 ou 11.

**[Télécharger la dernière version](https://github.com/AurelienDulaurier/cinecollection/releases/latest)**

Windows peut afficher « Windows a protégé votre ordinateur » : *Informations complémentaires > Exécuter quand même*. Ensuite, l'application se met à jour elle-même.

This product uses the TMDB API but is not endorsed or certified by TMDB.
